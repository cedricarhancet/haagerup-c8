# Révision documentaire v03

Cette livraison reprend les quinze commandes achevées et les résultats de `article-II-v14-supplements-v02`, commit `56fcf99d9f3249d2d39e55789ab8e89b2a34baf6`. Les sources mathématiques, les données, les reçus et journaux de calcul, ainsi que le source et le PDF v16, sont identiques. Les exécutions ne sont pas présentées comme recommencées pour cette révision documentaire.

Deux descriptions françaises de VERSION-CONCORDANCE avaient été lues avec le codage Windows par défaut : `local_v14.difference_from_hexagon` et `dependency_I.scope`. Elles sont rétablies depuis la référence UTF-8 de v01. Les liens de la documentation et des citations sont actualisés vers v03 ; les listes et manifestes sont recalculés.

Les calculs conservent leurs périmètres : CI0 sur 1 200 paires et trois modes, CI1–CI3 sur 180 paires chacun, puis les vérifications PCT et les contrôles du second moteur. Tous les bilans annoncés de la passe v02 sont achevés. Le source v16 cite toujours v02 ; ses données mathématiques restent les mêmes et cette release demeure disponible. Une nouvelle version du manuscrit n'est pas nécessaire pour cette seule correction de métadonnées.
