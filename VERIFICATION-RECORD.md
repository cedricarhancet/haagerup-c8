# Reçus des exécutions nouvelles

Le répertoire `checks/release-I-v14` contient les journaux et résultats du 7 novembre 2026. `CHECK-METADATA.json` distingue les opérations réalisées des régénérations non effectuées. `quick/RECEIPT.json` donne pour chaque commande le code de sortie, la durée, l'environnement et l'empreinte de son journal. `f4/verification.out` et `f4/f4_verified/` donnent les domaines et les appartenances contrôlés ; `zero-products-independent.json` répertorie les 886 zéros ; `COMPLETE-F4.json` est l'agrégation exhaustive. `certify_w3_validated.json` établit l'égalité exacte de la base S3 régénérée avec l'entrée archivée.

Le groupe `smoke-isolation` confirme l'exécution des commandes de démarrage avec les sorties dans un répertoire séparé. Les résultats C4 historiques sont conservés ; le nouveau résultat est dans ce répertoire de sortie.

La phase postérieure à la publication — téléchargement, empreintes et démarrage depuis une copie propre — est consignée dans le rapport privé. Elle ne transforme pas les journaux antérieurs en nouvelles exécutions.
